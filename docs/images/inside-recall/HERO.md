## Generation method and exact prompts

The tool accepts at most five local references. Stage one combined Library, Resources and English review into an intermediate three-phone composition. Stage two used that composition plus the three remaining native screenshots to create exactly six phones. The intermediate is a generation input only, not a published screenshot.

### Stage one

```text
Use case: compositing. Create a clean high-resolution landscape composite of THREE real Recall Android screenshot inputs, side by side, in exactly this order: Library, Resources, English review. Each screenshot must remain an intact legible content insert preserving every word, symbol, number, arrangement and color. Place each in a slim matching graphite Android phone with centered punch-hole, front-facing upright, full devices visible, equal size, generous narrow gaps. Warm off-white #F7F7F5 background, soft grounded shadow only. No captions, headlines, decorations, extra devices, overlap, glow, tilt, fake UI or Apple hardware. Preserve Mn²⁺ and [Ar] 3d⁵. This is an intermediate source composition for a six-screen marketing hero, not a new app interface. Target 2048x1536.
```
