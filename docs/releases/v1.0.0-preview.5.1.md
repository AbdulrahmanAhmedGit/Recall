## What's new

- **Pause subjects, chapters or lessons:** on Today, select a scope with Pause
  reviews, or use the container's own pause action. Choose today, seven days or an
  inclusive custom range. Parent rules also cover lessons added later. Overlaps
  remain independent; cancel a parent rule to remove its inherited pause.
- Pauses affect new mixed review queues, backlog batches and reminders—not due
  dates, memory state, history or explicit focused study. Existing lesson pauses
  remain compatible. Backup settings preserve all scopes; no Room migration.
- **Dynamic colors fixed:** shared selected, interactive and elevated surfaces
  inherit Android's wallpaper palette on Android 12 and newer.
- **Long tag layout fixed:** chips wrap into rows, with single-line labels and
  ellipsis where necessary, instead of shrinking into vertical character columns.
- **Thoughtful motion:** RTL-aware page/tab transitions, subtle action feedback,
  eased count/percentage updates, progress, review-card arrival and answer reveal,
  expandable Insights, and keyed list insertion/removal/reordering.
- Android's **Remove animations** setting takes effect live. TalkBack receives
  exact numerical targets rather than every animated intermediate value.
- All five languages, Inter/Cairo fonts, offline studying and normal FSRS behavior
  are preserved. No additional animation dependencies.

## Install

Download **Recall-1.0.0-preview.5.1.apk** and **SHA256SUMS.txt** below.
Android 7.0 (API 24) or newer; version code **6**.

This is an optimized, resource-shrunk, **non-debuggable preview**, approximately
4 MB—not the much larger development/debug APK. It remains **debug-signed** with
the existing preview certificate so compatible installations update in place.
It is not a managed store-signed production release.

**Export a full backup before updating.** Install over the existing app. Never
uninstall to resolve a signature mismatch without preserving your data first.

## Verification and boundaries

- 99 unit tests passed, including parent/overlapping pauses, backup compatibility,
  science/import/scheduling regressions and numeric interpolation.
- 14 targeted emulator tests passed: parent-pause persistence and legacy migration,
  newly added lessons, dynamic light/dark surfaces, long tags at enlarged font
  scale, live reduced-motion settings, list state, review restoration, notifications
  and all five interface languages including Arabic RTL.
- Debug/optimized builds and lint passed; existing lint warnings remain.
- Activity heatmap cells are not mass-animated. Physical low-end frame-time
  profiling remains useful; emulator checks do not guarantee a specific FPS.
- Already-open sessions remain snapshots. Calendar/analytics still reflect the
  underlying schedule; pauses do not modify it. Saved calendar intervals remain
  absolute instants after timezone changes.
- Older app versions restore lesson pause rules but do not understand the new
  parent rules. Other backup data remains compatible.
- Manufacturer battery restrictions and force-stop can still delay reminders.
