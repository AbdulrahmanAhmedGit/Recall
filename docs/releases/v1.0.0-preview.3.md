# Recall 1.0.0-preview.3 — Five offline languages

Recall now has real interfaces in **English, العربية, Español, Français and Deutsch**,
not just a layout-direction switch. Select a language in Settings → Appearance &
language → Language. System follows a supported device language, or falls back to
English. All translations are included in the APK and work offline.

## What's new

- Translated Today, Library, subject/chapter/lesson screens, resource management,
  card editors, import/validation, review controls, Insights, calendars, schedules,
  settings, onboarding, backup messages, pronunciation messages and reminders.
- Local dates, times, numbers, weekdays, plural forms, ratings and interval labels.
- Correct Arabic navigation direction and readable mixed Arabic/Latin content;
  scientific expressions and chronological timelines retain their ordering.
- Language switching takes effect immediately and persists across restarts and
  backup restores. Card text, subject names, tags, notes and filenames are untouched.
- Pronunciation uses lesson/target metadata, not the interface language. JSON keys,
  science markers and the provider-independent AI prompt keep their valid contract.
- Activity owners remain available to permission requests and document pickers
  when using localized resources. External Android settings and attached-file viewers
  launch through the real Activity. Settings choices expand and scroll for long text.
- Main content reserves space for the floating dock so it cannot intercept settings
  taps. Library quick-add is anchored visibly instead of being laid out offscreen.
- MIT license, contribution/security/support guidance, issue forms and repository topics.

No Room migration, study-data reset, scheduling change or new network dependency.
See the [feature guide](https://github.com/AbdulrahmanAhmedGit/Recall/blob/v1.0.0-preview.3/docs/features.md)
and [localization notes](https://github.com/AbdulrahmanAhmedGit/Recall/blob/v1.0.0-preview.3/docs/localization.md).

## Installation

Download **Recall-1.0.0-preview.3.apk** and **SHA256SUMS.txt** from this release.
Requires Android 7.0 (API 24) or newer; Android version code is 3.

This remains an **optimized, non-debuggable, debug-signed preview**, not a store-signed
production release. It uses the same signing certificate as prior public previews.
Export all data as a precaution and install over the previous preview to keep data.
If Android reports a signing mismatch, **do not uninstall without a full backup**.

## Boundaries

- Android's own settings/file picker/voice management use the OS language.
- The language selector is an in-app setting, not a separate Android per-app option.
- Battery restrictions, Doze and force-stop can still delay reminder delivery.
- FSRS predictions are estimates; unfinished review queues do not survive process
  death, although completed ratings are saved immediately.
- New translations have automated coverage and emulator checks; language feedback
  and real-device reports remain welcome.
