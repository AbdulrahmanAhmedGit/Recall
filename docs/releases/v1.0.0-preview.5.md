## What's new

- **Pause a lesson** for today, seven days, or an inclusive custom date range.
  It stays out of mixed Today reviews, backlog batches and reminder counts during
  that period. Resume it at any time; saved pauses expire automatically on checks.
- **Focused study** on a subject, optional chapter, or lesson. Available on Today,
  subjects, lessons and chapter action menus.
  - **Due cards:** normal scheduling and saved review history.
  - **Practice all cards:** includes future cards, without changing due dates,
    memory state, review history, activity or observed-recall statistics.
- Randomized focused sessions support up to **200 cards**; due mode retains the
  existing new-card limit. Suspended/archived content remains excluded. Explicit
  focus can include paused lessons.
- Pauses persist offline and are included in backups. Old backups remain
  compatible. No Room migration, FSRS equation change or data reset.
- All five interface languages are supported, including Arabic RTL. Inter and
  Cairo are included in this versioned release. New release and README artwork.

## Installation

Download **Recall-1.0.0-preview.5.apk** and **SHA256SUMS.txt** below. Requires
Android 7.0 (API 24) or newer. Android version code: **5**.

This is an optimized, resource-shrunk, **non-debuggable preview APK**, not the
approximately 26 MB debug build. It remains **debug-signed**, using the same
certificate as Preview 4 so compatible installations can update in place.
It is not a managed store-signed production release.

**Export a full backup before updating.** Install over the existing app; do not
uninstall to resolve a signature mismatch without preserving your data.

## Verification and boundaries

- 94 unit tests passed, including pause boundaries, DST and backup compatibility.
- 8 targeted emulator tests passed: focused/practice queues, pause persistence
  and resume, normal versus practice rating behavior, five-language UI including
  dark Arabic at 1.3× font scale, rotation, scheduling persistence and reminders.
- Optimized preview build and lint passed. Existing lint warnings remain.
- Pauses do not change underlying due dates or the read-only review calendar.
  Already-open sessions remain snapshots; pauses affect newly loaded mixed queues.
- An unfinished practice session does not resume after process death. Completed
  normal reviews and saved pauses persist. Practice is not counted in review analytics.
- Calendar ranges are converted to local day boundaries when saved. Later timezone
  changes do not reinterpret those saved absolute intervals.
- Manufacturer battery restrictions/force-stop can still delay reminder delivery.
