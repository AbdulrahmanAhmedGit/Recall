# Recall 1.0.0 Preview 5.2 — Find your way back

## What's new

- **Previous card:** revisit earlier questions, including rated and skipped cards.
  History is read-only: reveal answers without submitting another rating or
  changing FSRS, due dates, or review logs.
- **Swipe navigation:** swipe right to skip/next and left to go back in English,
  Spanish, French and German. **Arabic reverses this:** left for skip/next, right
  for previous. Vertical scrolling and navigation buttons remain available.
- **One-time gesture hint:** localized instructions appear on the first review
  card after this update, then stay dismissed across app restarts.
- Move forward through history to resume the unfinished question with its answer
  visibility preserved. Previous card is also available on session completion.
- Navigation is blocked while a rating saves; browsing history is excluded from
  the current question's foreground review timer.

## Install

Download **Recall-1.0.0-preview.5.2.apk** and **SHA256SUMS.txt** below.
Android 7.0 (API 24) or newer; version code **7**.

The optimized, resource-shrunk preview is non-debuggable but uses the existing
debug signing certificate for compatible updates. It is not a store-signed
production release. **Export a full backup before updating**, then install over
the existing app rather than uninstalling it.

## Verification and limits

- 101 unit tests passed, including history navigation and existing scheduling,
  import, science, analytics, backup and pause regressions.
- Four targeted emulator tests passed: mirrored gestures, short/vertical drags,
  disabled gestures, skipped/rated history, duplicate-rating protection, Activity
  recreation, one-time hint persistence and five-language navigation.
- Build and lint checks passed; existing lint warnings remain.
- History belongs to the current session. It survives Activity recreation, but
  ends when the session closes or the process terminates. It is not a permanent
  cross-session history browser.
- The hint acknowledgment is a local onboarding preference, not exported study
  data. No Room migration, FSRS equation changes or new dependencies.
