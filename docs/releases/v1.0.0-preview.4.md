## What's new

- Learning Insights now distinguishes New, Learning and estimated Mature memory
  (21-day FSRS stability). These are memory estimates, not comprehension scores.
- Observed Recall shows eligible, self-reported review outcomes over 30 days,
  with counts, small-sample explanations and limited optional attention suggestions.
- Expandable Current Predicted Recall uses the existing FSRS-6 forgetting curve,
  with explicit eligible-card coverage. It is not calibration against observed recall.
- Study Activity appears at the top of Insights. Cairo is bundled for the Arabic
  interface; all five interface languages and scientific notation remain supported.
- Newly submitted ratings use submission time consistently for scheduling and
  history. Changed interval predictions require another choice before saving.
- Foreground review duration and session progress survive Activity recreation;
  stale, duplicate, edited or inactive-card submissions are rejected atomically.
- Optional sessions of up to 20 cards appear at 60 due cards, oldest due first,
  respecting new-card preferences. Review-all remains available. Skipping or
  choosing a smaller session does not change untouched cards' due dates.
- Streaming JSON/ZIP backups address a demonstrated large-history memory failure.
  Stronger graph validation and transactional merge safeguards protect existing
  review states, history and attachments. Future-dated events are excluded from activity.

No Room migration, FSRS equation/parameter change, new dependency, calibration,
cloud service or automatic analytics-driven rescheduling. Existing data is preserved.
Historical presentation-time review timestamps are not rewritten.

## Verification and limitations

- 87 unit tests passed; 55 emulator tests passed, followed by 6 targeted backup checks.
- Optimized build and lint passed: 0 lint errors, 33 remaining warnings.
- Synthetic 10,000-card queues: bounded loading approximately 17 ms versus 143 ms
  for the full queue. These are emulator measurements, not real-device guarantees.
- A ZIP backup with 100,000 review events round-tripped successfully.
- Completed ratings survive app closure; unfinished sessions do not resume after
  process death. Real-device forced-kill, low-end scrolling and cancellation-race
  fault-injection checks remain pending.
- Room and preferences cannot commit as one transaction; restore reports a partial
  result if settings restoration fails after database commit.
- Manufacturer battery restrictions and force-stop can still delay notifications.
