# Recall 1.0.0-preview.2 — Calendar and reliability

Second public preview of Recall, the offline-first Android study companion built
around subjects, optional chapters and lessons.

## What's new

- **Review calendar:** open it from Today or Insights to see current next due dates,
  daily card counts and Q&A/Cloze/new/overdue breakdowns. Browse lesson-grouped cards,
  read their questions and answers, or open their lesson. Overdue cards stay under
  Today. Dates use local calendar boundaries, including DST changes.
- **More reliable reviews:** answers save atomically before advancing; stale or
  duplicate submissions are rejected. Delayed pronunciation links now update correctly.
- **Responsiveness improvements:** background JSON parsing and backup/file IO,
  bounded import reads, SQL-scoped subject queues, less hidden-screen work, cached
  reading annotations, lighter transitions and preserved main-tab scroll positions.
- **Consistency fixes:** archived content is excluded from due/reminder/calendar
  queries, and Insights attention rows open their lessons.
- **Smaller APK:** R8 optimization and resource shrinking, using a non-debuggable
  preview build.
- **Documentation:** a complete feature guide with 12 native demonstration screenshots,
  latest-change notes, and explicit 100% AI/Codex implementation credit under the
  project owner's direction and supervision.

Existing features remain: adaptive FSRS-6 reviews, Skip for now, completed-review
activity heatmap, universal AI JSON import, Arabic/Latin scientific notation,
offline pronunciation, subject notes/PDFs/photos, quiet times/study windows,
reminder diagnostics and full-data ZIP backups.

The calendar shows each card's **current next due time**, not every future repeat.
This update does not change FSRS equations, the AI import contract or the Room schema.

## Download and installation

Download **Recall-1.0.0-preview.2.apk** from the release assets. Requires Android 7.0
(API 24) or newer. Android application version code is 2.

This is an **optimized, non-debuggable, debug-signed preview**, not a store-signed
production release. The signing certificate matches the first public preview.
Install over the previous preview to retain existing data. Export all data first
as a precaution. If your installed APK uses another signing certificate, Android
will refuse an update: **do not uninstall without a full backup**.

The APK is accompanied by `SHA256SUMS.txt` for integrity verification.

## Verification and limitations

- Debug/test APK and optimized preview builds, 59 JVM tests and lint pass for this
  version. Lint has no errors; existing warnings remain.
- 5 calendar/review-persistence emulator regression tests pass for this version.
- APK metadata/signature checks confirm version code 2, Android API 24 minimum,
  and the first preview's signing certificate. The optimized APK installs as an
  update and launches on an API 34 emulator without resetting data.
- The preceding implementation pass also exercised 29 targeted emulator tests,
  review/navigation/pronunciation repeat tests, and optimized native screen smoke tests.
- Completed answers are durable, but an unfinished review queue is not restored
  after process death. Memory predictions are estimates, not guaranteed outcomes.
- Android battery restrictions, Doze and force-stop can still delay notifications;
  this release does not promise to bypass operating-system restrictions.
